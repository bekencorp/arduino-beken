# Beken Arduino Development Guide

Welcome to the Beken Arduino development documentation. This guide provides comprehensive information for developing applications on Beken series chips using the Arduino framework.

## Overview

This documentation covers everything you need to know about developing Arduino applications on Beken microcontrollers. The Beken Arduino framework provides a seamless integration between the popular Arduino ecosystem and Beken's wireless microcontroller solutions, enabling rapid development of IoT applications.

Key features of this framework include:
- Full Arduino API compatibility
- Support for Beken's BK7239N chip
- Integrated Wi-Fi and Bluetooth Low Energy connectivity
- Peripheral support (GPIO, PWM, ADC, I2C, SPI, UART)
- Easy setup and deployment tools
