# SPI

SPI (Serial Peripheral Interface) is a synchronous serial communication protocol widely used in embedded systems. It operates in a master-slave configuration with four signals:

| Signal | Name | Direction | Description |
|--------|------|-----------|-------------|
| SCK | Serial Clock | Output (Master) | Clock signal generated by the master |
| MOSI | Master Out, Slave In | Output (Master) → Input (Slave) | Data from master to slave |
| MISO | Master In, Slave Out | Input (Master) ← Output (Slave) | Data from slave to master |
| SS/CS | Slave Select/Chip Select | Output (Master) | Slave selection signal |

SPI uses a full-duplex, synchronous communication mode where data is transferred on both rising and falling clock edges depending on the SPI mode. The protocol supports four modes defined by clock polarity (CPOL) and clock phase (CPHA):

| Mode | CPOL | CPHA | Description |
|------|------|------|-------------|
| SPI_MODE0 | 0 | 0 | Clock idle low, sample on rising edge |
| SPI_MODE1 | 0 | 1 | Clock idle low, sample on falling edge |
| SPI_MODE2 | 1 | 0 | Clock idle high, sample on falling edge |
| SPI_MODE3 | 1 | 1 | Clock idle high, sample on rising edge |

Default SPI pins on the M39N DevKit:

| Board | SCK | MISO | MOSI | SS |
|-------|-----|------|------|----|
| M39N DevKit | P14 | P17 | P16 | P15 |

## SPI API Reference

### begin()

Initialize the SPI bus with default pins.

```cpp
void SPI.begin();
void SPI.begin(uint8_t SCK, uint8_t MISO, uint8_t MOSI, uint8_t SS = SS);
```

| Parameter | Type | Description |
|-----------|------|-------------|
| `SCK` | `uint8_t` | Serial Clock pin |
| `MISO` | `uint8_t` | Master In Slave Out pin |
| `MOSI` | `uint8_t` | Master Out Slave In pin |
| `SS` | `uint8_t` | Slave Select pin (optional) |

### end()

Disable the SPI bus and release pins.

```cpp
void SPI.end();
```

### beginTransaction()

Begin an SPI transaction with specific settings.

```cpp
void SPI.beginTransaction(SPISettings settings);
```

| Parameter | Type | Description |
|-----------|------|-------------|
| `settings` | `SPISettings` | Configuration for clock, bit order, and mode |

**SPISettings Configuration:**

The SPISettings class configures SPI communication parameters:

```cpp
SPISettings::SPISettings(uint32_t clock, BitOrder bitOrder, uint8_t dataMode);
```

| Parameter | Type | Description |
|-----------|------|-------------|
| `clock` | `uint32_t` | SPI clock frequency in Hz |
| `bitOrder` | `BitOrder` | Bit order (`MSBFIRST` or `LSBFIRST`) |
| `dataMode` | `uint8_t` | SPI mode (`SPI_MODE0` to `SPI_MODE3`) |

### transfer()

Send and receive data.

```cpp
uint8_t SPI.transfer(uint8_t val);
uint16_t SPI.transfer16(uint16_t val);
void SPI.transfer(void *buf, size_t count);
void SPI.transfer(void *txBuf, void *rxBuf, size_t count);
```

| Parameter | Type | Description |
|-----------|------|-------------|
| `val` | `uint8_t` or `uint16_t` | Value to send |
| `buf` | `void*` | Buffer to send and receive data |
| `txBuf` | `void*` | Buffer containing data to send |
| `rxBuf` | `void*` | Buffer to store received data |
| `count` | `size_t` | Number of bytes to transfer |

**Return:** Received byte or 16-bit value from the slave device.



## SPI Examples

### SPILoopback Example

**Initialization APIs:**
1. `SPI.begin()` - Initialize SPI bus with default pins
2. `SPI.beginTransaction(settings)` - Configure SPI settings (clock, bit order, mode)

**Communication APIs (in sequence):**
1. `SPI.transfer(data)` - Sends data through MOSI and receives data from MISO simultaneously
2. `SPI.endTransaction()` - End the current SPI transaction

**For loopback testing:**
- Connect MOSI pin to MISO pin physically
- The transmitted data will be received back, allowing verification of SPI functionality
- Use `SPISettings(clock, bitOrder, dataMode)` to configure desired communication parameters

```cpp
#include <SPI.h>

static const uint8_t kPattern[] = {0x55, 0xAA, 0x0F, 0xF0};

void setup() {
    Serial.begin(115200);
    Serial.println();
    Serial.println("arduino-beken spi loopback");
    Serial.println("Connect MOSI to MISO to observe mirrored bytes.");

    SPI.begin();
}

void loop() {
    SPI.beginTransaction(SPISettings(1000000, MSBFIRST, SPI_MODE0));
    Serial.print("TX/RX:");
    for (size_t i = 0; i < sizeof(kPattern); ++i) {
        uint8_t rx = SPI.transfer(kPattern[i]);
        Serial.print(" ");
        if (kPattern[i] < 16) {
            Serial.print("0");
        }
        Serial.print(kPattern[i], HEX);
        Serial.print("/");
        if (rx < 16) {
            Serial.print("0");
        }
        Serial.print(rx, HEX);
    }
    SPI.endTransaction();

    Serial.println();
    delay(1000);
}
```
