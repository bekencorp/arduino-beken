# Current support level:
# - Linux/Windows uploaders are distributed as a separate Boards Manager tool (bk_uploader);
#   Arduino IDE/CLI downloads the per-host archive and tools.bk-uploader.path resolves to {runtime.tools.bk_uploader.path}.
#   Local Arduino CLI staging overrides tools.bk-uploader.path.<os> with the in-tree tools/bk_loader/<os> root (see stage_platform.py).
# - macOS upload uses bk_loader from a manual .pkg install (default /usr/local/bin; override tools.bk-uploader.path.macosx in platform.local.txt)
# - compile/link consume a packaged arduino-beken SDK export
# - final image generation emits both {build.project_name}.all-app.bin and legacy all-app.bin
# - upload uses bk_loader directly against the sketch-specific all-app image
